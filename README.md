# competitive-programming

My competitive programming solutions and algorithm implementations in C++.

This repository documents my progress in problem-solving, data structures, and algorithmic thinking.

## Topics

- Dynamic Programming: Knapsack, Longest Increasing Subsequence (LIS), and more.
- Graph Algorithms: BFS, DFS, and graph traversal.
- Data Structures: Implementations and practice problems.
- Algorithms: Binary search, greedy techniques, and other problem-solving strategies.

## Repository Structure

- implementations/ — Algorithm implementations and reference code.
- solutions/ — Solutions to competitive programming problems from platforms such as Codeforces, CSES, and USACO Guide.

## Language

- C++17

This repository is a work in progress and will grow as I continue learning.
